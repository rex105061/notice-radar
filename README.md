## ⚠️ 免责声明

本项目输出内容**由 AI 生成**，仅供参考，**不构成任何投资建议**。使用前须经人工复核。
数据来源均为交易所、巨潮资讯网等**公开披露信息**，不涉及任何未披露信息或内部材料。

---

## 二、做什么 / 不做什么（MVP 边界）

**做**

| 环节 | 说明 |
|---|---|
| 数据获取 | 抓取 A 股公开公告（巨潮资讯网，交易所指定披露平台） |
| 结构化抽取 | 公司 / 公告类型 / 金额 / 交易主体 / 影响方向 / 关键条款 |
| 解读生成 | 一句话解读 + 机构可能关注点 + 建议对外口径 + 合规风险标记 |
| 交付形态 | 命令行 + 网页展示 |
| 质量证据 | 人工标注评测集 + 四维输出质量评估规范 + badcase 归因 |

**不做**（明确写下，防止范围蔓延）

- 用户系统 / 登录 / 付费
- 港股、美股、多语言
- 回测、估值模型、投资建议
- 自训模型 / 自建向量库

## 三、系统架构

```
┌─────────────────┐
│ 巨潮资讯网公开接口 │   A 股公告列表（沪深京全市场）
└────────┬────────┘
         │  fetch_notices.py
         ▼
┌─────────────────┐
│  SQLite 原始库    │   元数据 + PDF 正文纯文本
└────────┬────────┘
         │  extract.py（LLM）
         ▼
┌─────────────────┐
│  结构化 JSON      │   公司/类型/金额/主体/影响方向/关键条款
└────────┬────────┘
         │  interpret.py（LLM）
         ▼
┌─────────────────┐
│  解读 + 口径输出   │   解读 / 机构关注点 / 建议口径 / 合规风险标记
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
 cli.py    app.py (Streamlit)
```

## 四、快速开始

```bash
git clone https://github.com/rex105061/notice-radar.git
cd notice-radar

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt

cp .env.example .env            # 然后填入你的 DEEPSEEK_API_KEY

python src/fetch_notices.py --days 3
```
